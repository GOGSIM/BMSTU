# Лабораторная работа 3–4

Текстовый редактор на C++17 и Qt Widgets. Реализация обеих частей методички
«Разработка текстового редактора средствами Qt».

## План выполнения

1. Создать этот README, отдельную ветку Git и первый коммит документации.
2. Реализовать независимые документы во вкладках и файловые операции.
3. Реализовать стратегию чтения XML и настраиваемую подсветку синтаксиса.
4. Добавить меню, горячие клавиши, панель инструментов с ресурсами и два обозревателя.
5. Добавить подтверждение сохранения при закрытии вкладок и общий диалог выхода.
6. Собрать приложение, проверить сценарии и дополнить инструкцию защиты.

## Требования

- QMainWindow, QTabWidget, независимое редактирование обычного текста.
- QSyntaxHighlighter; расширения, регулярные выражения и оформление в XML.
- Чтение настроек через паттерн «Стратегия» без зависимости редактора от XML.
- Все команды меню «Файл», «Правка», «Вид» из методички и горячие клавиши.
- QDockWidget с QFileSystemModel и QStringListModel.
- Признак изменений `*`, сохранение при закрытии и QDialog с QTableWidget при выходе.
- Критические сообщения QMessageBox, стандартные QFileDialog.
- QToolBar с четырьмя значками из ресурсов; сообщения статуса на 5 секунд,
  постоянные строка и столбец курсора.

## Основа в учебных материалах

Лекция 4: QMainWindow, QAction, меню, панели, доки, строка состояния;
пример DocWindow (слайды 21–27) — основа редактора документа.
Лекция 5: цикл событий и closeEvent (слайды 6–7, 21).
Лекция 2 о Qt: контейнеры, QString, регулярные выражения, QFile и QTextStream.
Лекция STL: итераторы и алгоритмы для поиска по коллекциям.
Лекция 6 изучается как альтернативный подход Qt Quick; задание реализуется
на обязательных Qt Widgets. Стиль проекта продолжает ЛР2 и ДЗ2:
CMake, программное создание интерфейса, сигналы и слоты, комментарии на русском.

Обязательную подсветку дополняет пример из литературы методички:
[Syntax Highlighter](https://doc.qt.io/qt-6/qtwidgets-richtext-syntaxhighlighter-example.html).
Дополнения к лекционному примеру: проверка ошибок записи, безопасное сохранение
через QSaveFile, внешние настройки и контроль отмены закрытия.

Пока реализация не завершена; команды запуска и результаты проверок будут
добавлены после сборки. Отдельный отчёт и нумерация строк не входят в объём.
