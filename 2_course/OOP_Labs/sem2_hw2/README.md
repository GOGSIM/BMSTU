# Домашнее задание 2

## Использование XML и модели-представления Qt

Учебное приложение на C++17 и Qt Widgets отображает XML с данными московского
общепита в виде иерархической таблицы. Требования взяты из методички ДЗ2;
модель и представление основаны на лекции 3, главное окно и меню — на лекции 4.

## План выполнения

1. Подготовить четыре XML: кафе, кофейни, бары, быстрое обслуживание.
2. Реализовать `XmlTreeModel`, производную от `QStandardItemModel`: чтение
   через `QDomDocument`, создание дерева и обработка ошибок загрузки.
3. Создать `MainWindow` с меню «Файл», `QTabWidget` и `QTreeView`.
4. Добавить закрытие документов и перенос в отдельную вкладку.
5. Проверить модель и операции с документами, собрать и запустить приложение.
6. Дополнить этот README проверенными командами запуска и пояснениями для защиты.

## Критерии готовности

- В проекте есть четыре XML с реальными данными и описанным происхождением.
- DOM-разбор находится в классе модели с конструктором, принимающим имя файла.
- В дереве видны файлы, организации, характеристики и вложенные геоданные.
- Контекстное меню работает только у корней файлов.
- Перенос доступен при наличии хотя бы двух документов в исходной вкладке.
- Ошибки показываются критическим сообщением без потери ранее открытых данных.
- Сборка и проверки проходят; результат опубликован отдельной веткой и PR.

## Выбранные технологии

C++17, CMake, Qt 6.5 или новее, модули Widgets и Xml. Проверка на этой машине:
Qt 6.12.0, MinGW из комплекта Qt и Ninja. Интерфейс создаётся программно.
Комментарии и пояснения в коде — на русском, как в предыдущих работах.

Если прямые XML с data.mos.ru недоступны, разрешено преобразовать реальную
выгрузку портала в четыре XML по категориям. Такое преобразование должно быть
явно описано и не выдаваться за скачивание оригинальных XML.
