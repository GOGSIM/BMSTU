# Происхождение данных

Эти XML — результат преобразования реальных данных общепита Москвы, а не
оригинальные XML-выгрузки портала. Такой способ подготовки согласован отдельно,
поскольку data.mos.ru и найденные серверы выгрузок не ответили при выполнении.
Это отступление от буквального требования методички скачать готовые XML.

Первичный источник: [Портал открытых данных Москвы, общепит](https://data.mos.ru/opendata/1903).
Структуру и значения можно сопоставить с
[архивным примером набора](https://data.apicrafter.ru/tables/datamos/obshchestvennoe/sample).
Использована доступная [CSV-копия части набора](https://github.com/SergUSProject/BigDataProc_HomeWorks/blob/1c098ebd31d106d98c7d703ce4c09b3f26d98fef/spark/data/places.csv).
Описание столбцов есть в [сопроводительном файле источника](https://github.com/SergUSProject/BigDataProc_HomeWorks/blob/1c098ebd31d106d98c7d703ce4c09b3f26d98fef/spark/docs/BigData_HW1.md).
Из стороннего проекта взяты только данные; C++-реализация написана для этого ДЗ.

Копия получена 18 ноября 2026 года. Дата самой выгрузки в источнике не указана;
её нельзя считать актуальным справочником заведений. Исходные 769 записей
сохранены в `source/places.csv` без добавления заголовка.

| XML | Правило отбора | Записей |
| --- | --- | ---: |
| `cafes.xml` | `TypeObject = кафе` | 448 |
| `coffeehouses.xml` | Название содержит `кофе`, `coffee`, `cofix`, `starbucks`, `шоколадниц` или `costa`, без учёта регистра | 45 |
| `bars.xml` | `TypeObject = бар` | 131 |
| `fast_food.xml` | `TypeObject = предприятие быстрого обслуживания` | 15 |

В исходной копии нет типа «кофейня», поэтому вторая выборка является
эвристической: она не гарантирует полноту и может пересекаться с остальными.
Записи не выдуманы. Названия, адреса, телефоны, число мест, координаты,
`TypeObject` и `global_id` перенесены из CSV.

`provenance.json` содержит URL исходника, SHA-256 локальной CSV-копии,
распределение типов и число записей в каждом XML. Скрипт `tools/prepare_data.py`
позволяет повторить подготовку без сети. Он не требуется приложению при запуске.

## Поддерживаемая структура XML

Программа рассчитана на известную структуру этих четырёх файлов:

```xml
<?xml version="1.0" encoding="utf-8"?>
<catering category="Кафе">
  <organization>
    <global_id>123</global_id>
    <Name>Название</Name>
    <TypeObject>кафе</TypeObject>
    <AdmArea>Округ</AdmArea>
    <District>Район</District>
    <Address>Адрес</Address>
    <SeatsCount>0</SeatsCount>
    <Latitude_WGS84>55.75</Latitude_WGS84>
    <Longitude_WGS84>37.61</Longitude_WGS84>
    <PublicPhone><phone>Телефон</phone></PublicPhone>
  </organization>
</catering>
```

Этот фрагмент иллюстрирует формат, а не является реальной записью.
Для нескольких телефонов повторяется элемент `phone`. Отсутствующие значения
показываются как «Нет данных»; число мест `0` остаётся нулём.
Пустой `<catering/>` допустим и отображается как файл с нулём организаций.
Произвольные XML с другой структурой не поддерживаются.
