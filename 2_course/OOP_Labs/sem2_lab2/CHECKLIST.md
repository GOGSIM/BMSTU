# Проверка калькулятора

## Подготовка Qt в VS Code

1. Открыть в VS Code каталог `sem2_lab2` как отдельную папку.
2. В Qt Extension указать каталог установленного Qt SDK.
3. Выполнить команду `CMake: Select a Kit` и выбрать комплект Qt с совместимым
   компилятором.
4. Выполнить `CMake: Configure`.
5. Выполнить `CMake: Build`.
6. Запустить цель `sem2_lab2_calculator`.

Расширения VS Code не заменяют Qt SDK. Если CMake сообщает, что не найден
`Qt6Config.cmake` или `Qt5Config.cmake`, нужно сначала установить или подключить
Qt SDK.

## Обычный режим

- При запуске выбран переключатель `Обычный`.
- Заголовок окна имеет вид `Калькулятор (обычный)`.
- Инженерные кнопки скрыты.
- Повторный ввод точки не добавляет вторую точку.
- `12.5 + 7.5 =` выводит `20`.
- `9 sqrt` выводит `3`.
- `4 1/x` выводит `0.25`.
- `8 / 0 =` выводит `Ошибка`.
- После ошибки ввод цифры начинает новое вычисление.
- Кнопка `C` полностью очищает состояние.

## Инженерный режим

- После выбора режима окно расширяется.
- Заголовок окна имеет вид `Калькулятор (инженерный)`.
- Возврат в обычный режим снова сужает окно.
- Переключение режима не сбрасывает введённое число.
- `0 sin` выводит `0`.
- `0 cos` выводит `1`.
- `1 ln` выводит `0`.
- `100 log` выводит `2`.
- `2 x³` выводит `8`.
- `2 xʸ 10 =` выводит `1024`.
- `27 ³√x` выводит `3`.
- `27 ʸ√x 3 =` выводит `3`.
- `5 n!` выводит `120`.
- Кнопка `π` выводит число π.
- Логарифм отрицательного числа выводит `Ошибка`.
- Факториал дробного или отрицательного числа выводит `Ошибка`.

Тригонометрические функции принимают аргументы в радианах.

## Клавиатура

- Цифры и точка работают так же, как кнопки окна.
- Клавиши `+`, `-`, `*`, `/` выбирают операцию.
- `Enter` вычисляет результат.
- `Escape` очищает калькулятор.

## Финальная проверка Git

- В проекте нет `.ui`-файлов.
- В Git не добавлен каталог `build`.
- В Git нет исполняемых и пользовательских файлов VS Code.
- Рабочее дерево ветки чистое.
