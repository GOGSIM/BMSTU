# Лабораторная работа 2

## Двухрежимный калькулятор на Qt

Цель работы — разработать оконный калькулятор с помощью библиотеки Qt и
закрепить навыки программного создания интерфейса, размещения элементов и
обработки действий пользователя.

Калькулятор должен работать в двух режимах: обычном и инженерном. При первом
запуске выбирается обычный режим. Пользователь может менять режим с помощью
переключателей `RadioButton`.

В обычном режиме доступны:

- цифры от 0 до 9;
- ввод десятичной точки;
- сложение, вычитание, умножение и деление;
- вычисление квадратного корня;
- вычисление обратного числа `1/x`;
- получение результата и полная очистка.

В инженерном режиме дополнительно доступны:

- функции `sin`, `cos`, `tan`;
- функции `sinh`, `cosh`, `tanh`;
- экспонента, натуральный и десятичный логарифмы;
- квадрат и куб числа;
- возведение числа в произвольную степень;
- факториал и число π;
- кубический корень и корень произвольной степени.

После выбора режима интерфейс должен перестраиваться: инженерные кнопки должны
появляться или исчезать, а ширина окна — изменяться. Текущий режим должен быть
указан в заголовке окна в скобках.

Для отображения числа используется однострочное поле с моноширинным шрифтом.
Интерфейс создаётся программно, без Qt Designer. Элементы размещаются с помощью
автоматических компоновщиков Qt.

## Быстрый запуск

Если проект уже собран, а терминал PowerShell открыт в корневой папке `BMSTU`,
калькулятор запускается командой:

```powershell
.\2_course\OOP_Labs\sem2_lab2\build\sem2_lab2_calculator.exe
```

При отсутствии файла сначала нужно открыть `sem2_lab2` в VS Code и один раз
запустить настроенную сборку клавишей `F5`.
